# 持仓文件账本说明

本目录用于保存人工可读的持仓快照说明。

- 权威持仓数据：`data/ledger/holdings.csv`
- 权威交易数据：`data/ledger/trades.csv`
- 权威关注清单：`data/ledger/watchlist.csv`
- 来源：由旧 SQLite `data/investment_data.db` 迁移导出，并保留旧库归档备份。
- 维护方式：后续通过脚本或手动编辑 CSV 维护；项目运行不再依赖 SQLite。

## 持仓快照

- `2026-08-05_持仓截图提取.md`：当前最新支付宝基金持仓，14 只基金，已确认总金额 6667.26 元；另有买入待确认 90.00 元未并入已确认持仓。截图已人工核对，更新时桌面原附件已不存在，未归档图片实体。
- `2026-07-20_持仓截图提取.md`：历史支付宝基金持仓，14 只基金，总金额 5673.92 元；原图见 `source/2026-07-20/`。
- `2026-06-12_持仓截图提取.md`：历史基金与牧原持仓快照，仅供复盘，不再代表当前持仓。

快照按日期保存，最新快照优先。若最新截图中存在“买入待确认”，先记录待确认总额，不在未知具体基金时自行补写交易流水。

注意：个人持仓和交易记录优先保护；行情缓存可重新拉取，但迁移时也会尽量保留。
