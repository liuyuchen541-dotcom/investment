# 投资文件夹使用说明

这个文件夹保存用户的长期投资分析上下文，供 Codex 以后作为投资助手时优先读取。

## 文件结构

- `投资理念.md`：最高优先级的中心思想，整理自用户长期跟随学习的投资博主录音稿。
- `投资总框架.md`：共用投资风格、资金池边界、每日分析流程、总纪律和风险提示。
- `基金/基金投资上下文.md`：基金持仓、基金代码、补仓规则、止盈规则、宽基计划和基金专项纪律。
- `基金/宽基指数投资理念.md`：巴菲特赌局、低成本宽基指数、承认无知、长期持有和少操作理念。
- `股票/股票通用方法论.md`：股票建仓、加仓、持有、卖出的通用原则。
- `股票/高股息资产投资理念.md`：流动性危机错杀、高股息现金流底仓、股息陷阱识别和攻守配置。
- `股票/牧原股份/牧原股份投资上下文.md`：牧原股份当前 8 万元阶段预算、已确认持仓、统一目标仓位、上涨/回调加仓规则和暂停补仓条件；原 5 万元金字塔表仅作历史基线。
- `股票/牧原股份/研究材料/`：牧原股份外部报告、AI 分析和阶段性研究快照，使用前必须重新核验实时数据。
- `黄金/黄金投资理念.md`：黄金长期主义、反投机和净买入者视角。
- `00_原始上下文/基金与牧原股票投资策略上下文.docx`：原始 Word 母文档，作为备份来源，不直接修改。

## 以后如何使用

当用户问基金相关问题时，先读取：

1. `投资理念.md`
2. `投资总框架.md`
3. `基金/基金投资上下文.md`
4. 如涉及宽基、主动基金选择、长期基金底仓，再读取 `基金/宽基指数投资理念.md`

当用户问普通股票方法论或个股相关问题时，先读取：

1. `投资理念.md`
2. `投资总框架.md`
3. `股票/股票通用方法论.md`
4. 如涉及高股息、分红现金流、危机错杀，再读取 `股票/高股息资产投资理念.md`

当用户问牧原股份相关问题时，先读取：

1. `投资理念.md`
2. `投资总框架.md`
3. `股票/股票通用方法论.md`
4. `股票/牧原股份/牧原股份投资上下文.md`
5. 必要时读取 `股票/牧原股份/研究材料/README.md`

当用户问黄金相关问题时，先读取：

1. `投资理念.md`
2. `投资总框架.md`
3. `黄金/黄金投资理念.md`

如果用户同时问多个品类，对应上下文都要读取，但不同资金池必须分开计算。

## 当前事实与历史材料

项目中的投资理念和策略可以长期使用，但持仓、余额、成本、收益率和行情会过期。读取时按以下优先级判断事实：

1. 用户最新明确确认的信息或最新持仓截图；
2. `investment-assistant/data/ledger/` 中带更新时间的持仓与交易记录；
3. 各品类上下文中明确标记为“当前有效”的内容；
4. 带日期的持仓快照、阶段判断和研究材料，仅作历史参考。

交易流水只证明发生过一笔交易，不自动等于最新持仓。若账本更新时间早于后续交易，或不同文件数据冲突，必须先向用户核对，不得自行推算为当前事实。

根目录上下文更新后，应同步到 `investment-assistant/docs/context/`。应用副本不得比根目录主文件旧。

## 录音稿 txt 处理规则

以后如果用户把桌面上的录音稿、视频转录稿或学习笔记以 `.txt` 格式交给 Codex，默认处理流程是：

1. 读取原稿；
2. 提炼成投资理念、品类规则或研究摘要；
3. 写入对应 Markdown 上下文；
4. 校验关键内容；
5. 将原始 txt 移入回收站，不永久删除。

## 重要纪律

这些文件是个人投资纪律和分析上下文，不是自动交易脚本，也不是固定收益承诺。

每次给建议前，必须结合：

- 当天真实行情；
- 用户最新持仓截图；
- 基金净值/估值；
- 行业新闻；
- 政策变化；
- 黄金、股票或牧原相关基本面变化；
- 预设补仓/止盈条件是否真的触发。

不能只根据单日涨跌给出操作建议。
